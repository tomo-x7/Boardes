# 変更点まとめ (Phase 10〜19)

`OVERVIEW.md` (初版時点の説明) からの差分を記録する。実装時に見つかった座標系バグの
修正が主目的だったが、そこから派生してライブラリ機能・カスタマイズ機能を広く作り直した。
本ファイルはその結果としての UI 変更点のみを記録し、実装判断の経緯そのものは
`/home/tomo/.claude/plans/parallel-frolicking-lantern.md` を正とする。

対応するスクリーンショット (`screenshots/`) は本ファイル末尾の一覧を参照。

## メインウィンドウ

- **ツールバー(2段目・ツール系)**: 「配線(表)/配線(裏)/被覆(表)/被覆(裏)」の4ボタンを
  「配線/被覆配線/外形線」の3ボタンに整理。**どちらの面に描くかはボタンでは選ばなくなり、
  表面ビュー/裏面ビューどちらのエディタでクリックしたかで自動的に決まる**(`WireKind` +
  `BoardScene::side()`)。
- **右ドック**: タイトルを「解析」から「パネル」に変更 (`objectName` も `analysisDock` →
  `sidePanelDock`)。タブ構成が「DRC/統計」の2つから **「オブジェクト/DRC/統計」の3つ**に
  なり、Office アプリのオブジェクト一覧に相当する新しいタブが先頭に増えた
  (下記「新規画面」参照)。
- **DRC パネル**: 「再検査」ボタンを削除。元々編集のたびに自動再計算されており実質的に
  リアルタイムだったため、唯一の非リアルタイムな穴 (ライブラリの変更) を
  `LibraryManager::librariesChanged` シグナル経由の自動再計算に置き換えて塞いだ。
- **ステータスバー**: 右端に**倍率バー**(縮小/スライダー/拡大 + 編集可能なパーセンテージ
  コンボ)を追加。既定倍率が低すぎて起動直後に何も見えない問題があったため、基板が
  設定されたら自動的に全体表示になるよう変更した。
- **表示メニュー/ツールバー**:
  - 「裏面の見え方」サブメニューを追加。**裏から見た向き(左右反転・既定)/透過した向き
    (左右そのまま)/裏から見た向き(上下反転)**の3択で、裏面ビューの見た目を切り替えられる。
    文字ラベルは選んだモードに応じて鏡文字にならないよう自動補正する。
  - 「表裏のビューを連動」トグルを追加。ON にすると、表裏どちらかのビューをスクロール/
    ズームしたとき、モデル空間上の同じ点が中心に来るようもう片方が追従する。
  - 「接点マーカーを表示」トグル + 「接点マーカーの色...」を追加。ON にすると全ピン位置に
    指定色の丸を重ねて表示する(既定: 赤・直径3単位)。PasS 部品はインポート時に元の赤い
    マーカー画素をもう消さなくなった(後述)ので、ONにすると**その上にさらに丸が重なる**。
  - 表示メニュー末尾に、ツールバー・ドックの表示/非表示トグル(`toggleViewAction()`)と
    「操作のカスタマイズ...」「ツールバーのカスタマイズ...」を集約した
    (メニューバー自体はカスタマイズ対象外。LibreOffice に倣う)。
  - 小さな字の説明ラベルをすべて「？」ボタンのホバー/クリックに置き換えた(下記
    「注釈の？化」参照)。**唯一の例外はステータスバー左のリアルタイム操作ヒント**
    (GIMP 風。「クリックで配置 / R:回転 / 右クリックまたはEsc:解除」のような文言で、
    今アクティブなツールの操作方法を常時表示する)。これはそのまま維持し、Phase 18 の
    ショートカットカスタマイズを反映するよう文言が動的に変わるようにした。
- **「ライブラリ」メニュー**: 「ライブラリ管理...」の1項目のみになった。「ファイル→
  インポート」サブメニュー(PasS フォルダ/部品ファイル/基板ファイル)と、部品・基板の
  新規作成メニューは廃止し、すべて「ライブラリ管理」ダイアログの中に集約した。
- **座標系・操作性のバグ修正**(画面上の見た目は変わらないが、動作が大きく変わった):
  - 部品配置・配線のスナップ位置が基板の格子(origin/pitch)からずれていたバグを修正。
  - 部品に「基準点(anchor)」の概念を追加(既定はピン1)。配置時にこの点が穴の中心へ
    スナップするようになり、ピンが穴からずれる問題が解消した。
  - 裏面ビューで配置・配線すると左右反転した位置に入ってしまうバグを修正。
  - 部品パレットは**ダブルクリックからシングルクリック選択**に変更し、選択すると
    「配置中: 品名 [解除]」というバーが出るようになった。配置ツール中はカーソル位置に
    半透明のゴースト(配置プレビュー)が出る。
  - 配線の確定は「右クリックまたは Enter」に統一(ダブルクリックでは確定しなくなった)。
  - Esc キーがウィンドウ内どこにフォーカスがあっても効くようになった(途中状態があれば
    破棄、無ければ選択ツールに戻る)。
  - 選択中の部品・配線が二重枠+四隅ハンドルではっきり分かるようになった(以前は選択の
    可視化がほぼ無かった)。

## ライブラリ管理

最も大きく変わった画面。以前の「リスト+5ボタン」から、**ツリー+詳細+操作群のハブ**に
全面刷新した。

- 左側がツリー表示(`ライブラリ名 → カテゴリ → 部品` / `基板`)になり、**カテゴリ・部品・
  基板を直接ブラウズ・編集・削除できる**。
- 「新規ライブラリ」でライブラリを1から作成できる(以前は複製でしか増やせなかった)。
- **「読み込み専用」の概念を廃止**。すべてのライブラリが編集可能(部品追加・カテゴリ編集・
  メタデータ編集)になった。マイライブラリ・PasS互換ライブラリも削除でき、削除すると
  空の状態で自動的に再作成される。
- **「他ライブラリから複製」**(新しい部品ピッカー画面、後述)で、任意のライブラリから
  部品・基板をコピーしてこのライブラリに取り込める。
- **エクスポートは常に可能**になった。以前は再配布不可のライブラリはエクスポートボタン
  自体が無効化されていたが、「バックアップ・自分用の持ち出しは自由、公開・配布だけ
  控えてほしい」という方針に変更したため、**再配布不可のライブラリを書き出そうとすると
  警告ダイアログが出た上で、それでも書き出せる**ようになった。
- 「ファイル→インポート」で分かれていた PasS フォルダ取込・部品ファイル取込・基板
  ファイル取込のボタンも、このダイアログの「取り込み」グループに集約された。

### ライセンス種別の削減

`CC0 / CC BY 4.0 / MIT / 全権利留保(既定) / カスタム` の**5種類**に削減
(旧: CC0/CC-BY/CC-BY-SA/CC-BY-NC/MIT/Apache-2.0/CERN-OHL-P/CERN-OHL-S/全権利留保/
カスタムの10種類)。カスタムのみ、再配布可否・表示義務をユーザーが手動で指定できる。
「派生ライブラリのライセンスを複製元に合わせて固定する」制約(コピーレフト強制)も廃止し、
複製時のライセンス選択は自由に選べるようになった。廃止した種別は、古いデータを読んだ
ときには「カスタム」として名前・URL付きで表示される(黙って読めなくなることはない)。

## 新規画面

- **部品ピッカー**(`partpickerdialog`): 「他ライブラリから複製」用。単一のライブラリを
  選び、検索・複数選択して取り込む。取り込み元が再配布不可の場合、取り込み先の
  「取り込み元」情報にその旨が記録される。
- **パッケージエクスポート**(`exportpackagedialog`): `.bpkg` 書き出し時、同梱する依存
  ライブラリをチェックボックスで選ばせる。再配布可のものは既定でON、不可のものは既定OFF
  +赤字で「再配布不可」と表示し、それでもONにして進むと警告する。
- **操作のカスタマイズ**(`keymapdialog` + `gesturecapturedialog`): ショートカットキー・
  マウス操作(クリック/ダブルクリック/ドラッグ)の割り当てをコマンド単位で変更できる。
  「割り当てを追加」で表示される捕捉ダイアログに、変更したいキー/クリックを実際に
  入力すると登録される。Qt がキー名を認識できないキー(左手デバイス等)は
  `nativeScanCode` で識別し、「スキャンコード #191」のように表示・登録できる。
  同一カテゴリ内(+全体共通)での重複は赤字で警告表示するが、保存はブロックしない。
- **ツールバーのカスタマイズ**(`toolbarcustomizedialog`): LibreOffice 風。既定の
  「表示」「ツール」ツールバーは表示/非表示とボタンスタイル(アイコンのみ/文字のみ/
  アイコンと文字/アイコンの下に文字)を変更できる。**「新しいツールバー」**で、
  既存の登録済みコマンドから自由に選んで独自のツールバーを作成・並べ替え・
  区切り線の挿入ができ、名前変更・削除もできる(既定の2つは削除・項目編集不可)。

## 基板エディタ

- **「画像から作る」/「パラメトリック(画像なし)」の2モード切替**を追加。
  - 画像モードでは表面画像が必須になり、パッド形状・銅箔パターン・両面・色ピッカー等の
    項目が非表示になる(背景画像がすべてを表現するため)。
  - パラメトリックモードでは逆に背景画像欄が非表示になり、色・パッド・銅箔の指定欄が出る。
- 新規作成時のタイトルが「基板を作成」、OK ボタンが「作成」になった(以前は編集時と
  同じ「編集」表記のままだった)。編集時は「基板を編集」/「保存」。

## 部品エディタ

- **基準点(anchor)の指定**を追加。既定は「自動(ピン1: x,y)」で、キャンバス上のボタンで
  手動指定に切り替えられる(緑の十字+丸で表示。ピンの赤/青丸とは別色)。「自動に戻す」
  ボタンもある。
- 新規作成時のタイトルが「部品を作成」、OK ボタンが「作成」になった(編集時は
  「部品を編集」/「保存」)。
- 「ピン一覧」等の説明ラベルは「？」ホバーに変更。

## 注釈の「？」化

小さい字の説明ラベルを画面に常駐させる方式をやめ、「？」ボタンのホバー/クリック、または
入力欄・ボタン自身のツールチップで説明を出す方式に統一した。対象は基板エディタの背景
画像規約、部品エディタのピン一覧操作方法、配線スナップコンボ、画像エクスポートの各項目、
表示メニューの各トグル等。**動的な状態表示(導出サイズのバナー、ライセンスのプレビュー
文言など)は注釈ではないため対象外**、そのまま残している。

## 画像だけでは分からない挙動(追加分)

- **破損データの扱い**: `.boardes`/`.bpkg`/`.blib`/`library.json`/`.bpart`/`.bboard` の
  すべてで読み込み時にスキーマ検証を行うようになった。壊れたファイルを開こうとすると、
  理由付きのダイアログが出て「ファイルを削除」「詳細をコピー」「閉じる」から選べる。
  起動時にアプリ自身が管理するライブラリの一部が壊れていた場合も、まとめて警告し
  削除するかどうか選べる。設定 (`QSettings`) の壊れた値は個別に既定へフォールバックし、
  ダイアログは出さない。
- **接点マーカー**: PasS 部品インポート時、以前は元の赤いマーカー画素を周辺色で
  塗りつぶして消していたが、**塗りつぶしをやめて元の画素をそのまま残す**ように変更した
  (「接点マーカーを表示」ON にすると、その上にさらに丸を重ねて描く)。
- **オブジェクト一覧タブ**: 部品・配線を階層ツリーで一覧でき、行頭の目のアイコンで
  個別に表示/非表示を切り替えられる(`Placement`/`Wire` に `visible` フィールドを追加し、
  Undo 対象になった)。行をダブルクリックすると両ビューがその要素を中心に表示する。
  右クリックで削除・回転・表裏切替・表示切替ができる。
- **裏面ビューのパン**: 以前は基板がぴったり画面に収まると外側へスクロールできなかった
  (シーン範囲=基板ぴったりのバグ)。基板の周囲に余白を持たせるよう修正した。
