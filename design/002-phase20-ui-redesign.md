# 変更点まとめ (Phase 20: UI 刷新)

claude.ai/design「Boardes UI」プロジェクトで確定した刷新デザイン(`Boardes UI 刷新仕様書.html` +
`screens/redesign-*.html` モックアップ、ライト/ダーク各13画面)を実装した。`OVERVIEW.md` /
`001-phase10-19-ui-changes.md` からの追加の差分としてここに記録する。実装判断の経緯そのものは
`/home/tomo/.claude/plans/majestic-rolling-zephyr.md` を正とする。

対象は QSS・アイコン・フォント埋め込み・レイアウト微調整で実現できる範囲(メニュー・
ツールバー・ドック・パネル・入力欄などの「額縁」部分)。`QGraphicsView` キャンバス内部の
描画色(配線色・ネットハイライト・選択ハンドル・部品エディタのピン色)は仕様どおり対象外。

## 配色・フォント基盤

- **カラートークン**: ニュートラルグレーのみ(surface-0〜3・border-subtle/strong・
  text-primary/secondary/disabled)。ブランドカラーは無く、選択/チェック状態もグレーの濃淡
  だけで表現する。DRC のエラー/警告と About のリンクだけ意味のある色を持つ(`Theme` クラス
  経由、ライト/ダークで値が異なる)。配線色(表=青/裏=オレンジ)はテーマに関わらず固定。
- **ライト/ダーク**: `resources/qss/light.qss` / `dark.qss` を丸ごと用意し、起動時に
  `QGuiApplication::styleHints()->colorScheme()` で判定して適用、`colorSchemeChanged` で
  実行時追従する(`src/ui/theme.{h,cpp}` の `Theme` シングルトン)。
- **フォント**: Noto Sans JP 可変フォント(Regular〜Bold を1ファイルでカバー、約9.6MB)を
  `resources/fonts/` に埋め込み、起動時に登録して既定フォントにする(SIL OFL、
  `THIRD_PARTY_NOTICES.md` と About 画面に表記を追加)。数値専用フィールド(スピンボックス・
  ID欄・hexコード・ズーム%)は等幅フォント(`Theme::monoFont()`、または `qproperty` 的な
  `setProperty("mono", true)` + QSS `[mono="true"]` セレクタ)。
- **既知の落とし穴**: `resources/boardes.qrc` は静的ライブラリ `boardes_core` 側にリンクされて
  いるため、何も参照しないと埋め込みリソースの初期化コードごとリンカに捨てられる
  (Qt の既知の注意点)。`Theme::init()` 冒頭で `Q_INIT_RESOURCE(boardes)` を呼んで防いでいる。

## アイコン

- 表示ツールバー(1段目)・ツールツールバー(2段目)を**アイコンのみ+ホバーでツールチップ**に
  変更(`Qt::ToolButtonIconOnly` が既定。`ToolbarCustomizeDialog` で従来どおりテキスト表示にも
  戻せる)。アイコンは claude.ai/design モックアップに実際に描かれているインラインSVGパスを
  そのまま `src/ui/icons.{h,cpp}` に転記し、`QSvgRenderer` で指定色にラスタライズしている
  (`text-secondary`/`text-primary` の2状態、配線系トグルは固定色+50%/100%不透明度)。
- ツールツールバーの排他6ボタンは「チェック時は下端に太い線」、配線系トグルは「アイコン
  自体の色」で表現する(`QToolButton` に `toolAction`/`wireSide` プロパティを付与、QSS側で
  セレクタ)。

## メインウィンドウ

- 表面/裏面ビューヘッダは `objectName("viewHeaderFront"/"viewHeaderBack")` に切り替え、
  下線を配線色(青/オレンジ)にした(直書き `setStyleSheet` を廃止)。
- 右ドック「パネル」はタイトルバーを廃止し、タブ列が最上部に来るようにした
  (`QDockWidget::setTitleBarWidget()` に空ウィジェットを渡す。フロート化はできなくなるが
  実害なし)。
- DRC 重要度の文字色・About のリンク色・操作カスタマイズ/パッケージエクスポートの警告文字色を
  `Theme` 経由の値に置き換え、ライト/ダークどちらでも正しい色になるようにした。
- ステータスバーの倍率バーの縮小/拡大ボタンをテキスト(－/＋)からアイコンに変更、
  パーセンテージ表示は等幅フォント。
- 「？」ヘルプバッジを 18×18px → 仕様書どおり 13×13px に縮小。

## ダイアログ共通

- **色スウォッチ**: 基板エディタの基板色/パッド色/銅箔色は「色を背景に文字を重ねる」ボタンを
  廃止し、正方形スウォッチ+隣に等幅フォントの hex 表示に変更(どんな色でも文字が読めなく
  なる事故を防ぐため)。部品エディタのクロマキー色ボタンは仕様どおり従来の表現を維持
  (色そのものを見せる必要がある機能)。
- **ID/バージョン等の等幅化**: 基板/部品エディタの ID 欄、ライブラリ管理の詳細パネル、
  複製ダイアログの ID/バージョン欄など。
- **ライブラリのメタデータ編集は ID 欄を非表示に**(仕様書どおり。複製ダイアログにのみ
  ID 欄を残す。既存ライブラリの ID は編集不可なので表示する意味が薄いため)。
- **部品エディタのピン一覧を複数選択可に**(`QAbstractItemView::ExtendedSelection`)。
  「選択したピンを削除」が複数行に対応した(仕様書は「チェックボックス列」との二択を
  明示的に許容しており、実装コストの低いこちらを採用)。
- **基準点マーカー色**を固定色 `#3DBE5B` に統一(部品エディタのキャンバス)。
- **既定ボタンの誤爆を修正**: Qt は `QDialog` 内の最初の `autoDefault` な `QPushButton` を
  暗黙に「既定ボタン」として黒塗り強調してしまう。ライブラリ管理・部品/基板エディタ・
  ツールバー/操作のカスタマイズなど、単発アクションボタンを多数並べるダイアログでは
  これが「これが主要アクションだ」という誤った印象を与えるため、`Theme::suppressAutoDefault()`
  で `QDialogButtonBox` 配下以外のボタンの autoDefault を一括で無効化した。

## 今回は変更しなかった/近似にとどめたもの

- **ライブラリ管理のボタングループ見出し**: `QGroupBox` のネイティブタイトルはフル幅バーに
  できないため、太字+下線色の近似にとどめている。
- **ツールバーアイコンのホバー時の線色変化**: 背景ハイライトのみで表現し、線の色自体は
  変えていない(Off/On の2状態のみ生成。実装コストと実益のバランスから見送り)。
- **部品エディタのキャンバス背景色**: `PartArtworkCanvas` は `palette().color(QPalette::Dark)`
  を使っており、仕様書が言う固定色 `#3C3C3C` とは一致しない(実測 `#9F9F9F`)。これは
  Phase 20 以前から存在する差分で、キャンバス内部描画は今回のスコープ外のため変更していない。
- **オブジェクト一覧の目玉アイコン**: モックアップは目のアイコンだが、実装は
  `QTreeWidgetItem` のネイティブチェックボックスのまま(機能は同じ)。
