# 変更点まとめ (下書きの消去アクション)

`003-phase20-review-fixes.md` からの追加の差分。下書き (下書きツールで描くフリーハンドの線) を
消す手段が無かったため、編集メニューに「下書きを消去」を追加した (GitHub issue #1)。

## 編集メニュー: 「下書きを消去」

- **場所**: 編集メニューの「元に戻す」「やり直す」の下 (区切り線を挟む)。
- **動作**: 表面・裏面の両方の下書きをすべて消す。確認ダイアログは出さない。
- **元に戻せない**: 下書きは設計データではなく、ツールが描く表示専用の一時的な線 (保存も
  エクスポートもされない)。そのため Undo スタックには積まず、「元に戻す」では戻らない。
  ツールチップにもそう書いてある。
- **有効/無効**: 表面か裏面のどちらかに下書きが1本でもあるときだけ押せる。ストロークを描き終える
  (ボタンを離す) と押せるようになり、消すと押せなくなる。描いている最中のストロークは数えない。
- **ツールバー**: 既定のツールバーには置かない。「ツールバーのカスタマイズ」の「利用可能な
  コマンド」に「下書きを消去」(コマンド ID `toolbar.tools.clearDraft`、「下書き」の次) が増えた
  ので、「新しいツールバー」を作れば置ける。アイコンは付けていない (文字表示のボタンになる)。
- **ショートカットキー**: 割り当てていない。「操作のカスタマイズ」の対象はキャンバス上のツール操作
  (`select.*` / `wire.*` / `draft.stroke` など) で、メニューやツールバーのコマンド (新規作成・
  保存・元に戻す等) のショートカットは `QAction` 側で決まっているため、同じ扱いにした。取り消せない
  操作なので、押し間違えやすい既定のキーも付けていない。

## 設計データを入れ替えたとき

ファイル→新規作成・開く (最近使ったファイルを含む) で設計データを入れ替えても、これまでは下書きが
残ったままだった (下書きを描くオーバーレイは `BoardScene` の生成時に1度だけ作られ、消す手段も
無かったため)。入れ替えたら下書きも消えるようにした (`BoardScene::setDocument()`)。
