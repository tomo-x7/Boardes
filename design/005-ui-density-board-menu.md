# 変更点まとめ (情報密度・ツールチップ・基板メニュー・配線の太さ)

`004-clear-draft-action.md` からの追加の差分。使い込む道具として、GIMP や 3D CAD と同程度の
情報密度に寄せた。あわせて、ツールチップの書き方の統一、基板を選ぶ導線の追加、配線を太くする
変更を入れた。

## 情報密度

- **余白を詰めた** (`resources/qss/light.qss` / `dark.qss`、セレクタ構成は両者で同じまま):

  | 対象 | 以前 | 以後 |
  | --- | --- | --- |
  | ツールバー (`QToolBar`) の内側余白 / 間隔 | 4px 8px / 2px | 1px 2px / 1px |
  | ツールボタン (`QToolButton`) の内側余白 | 6px | 3px |
  | メニュー項目 (`QMenu::item`) | 6px 24px 6px 14px | 3px 20px 3px 10px |
  | メニューバー項目 | 4px 10px | 2px 8px |
  | タブ (`QTabBar::tab`) | 8px 16px | 4px 10px |
  | 入力欄 (コンボ・テキスト・スピン) | 5px 8px | 2px 5px |
  | 表の見出し (`QHeaderView::section`) | 6px 10px | 2px 6px |
  | 表・ツリーの行 | 3px | 1px 3px |
  | ボタン (`QPushButton`) | 6px 14px | 3px 10px |
  | 表面/裏面ビューの見出し | 12px・上下 6px | 11px・上下 1px |
  | スクロールバーの幅 | 12px | 10px |

- **文字を 9pt に** (以前は 10pt。`Theme::init()`)。
- **ツールバーを1行に**。表示ツールバーとツールツールバーを同じ行に並べた (以前は2行)。
  アイコンの枠も 24px → 16px にした (アイコン自体は以前から 14px で描いていて、24px 枠では
  周りが空いていただけ)。表示ツールバーで「表裏のビューを連動」の後ろに区切り線が2本続いていた
  のを1本にした (「裏面の見え方」はメニューにしか無いのに、その前後に区切り線を入れていたため)。
- **部品セレクタ**:
  - 「ライブラリ別/カテゴリ別/全部品」とライブラリの選択を1行に並べた。
  - アイコン表示を 48px + 名前の折り返しから、32px + 名前1行 (はみ出したら「…」で省略) の固定
    マスにした。サイドバーの既定幅で3列 → 4列になり、1マスの高さも縮んだ。
  - 検索欄の右に**リスト表示の切替**ボタンを追加した。ON にすると 20px のアイコンと名前を1行ずつ
    並べる。状態は `QSettings` の `partSelector/listMode` に保存する。
- **ステータスバーにカーソル位置**を常に出す (`X 12.70  Y 5.08 mm`、右端)。裏面ビューでも基板を
  表から見た座標。ビューの外に出ると消える。

## ツールチップ

「押すと〜します」「ON にすると〜」のような説明文をやめ、**何であるかを名詞句で短く**書く方針に
統一した。

- ツールバー: 「表面配線の表示」「表裏ビューのスクロール・倍率を連動」「倍率 100%」
  「配線のスナップ間隔」「表裏の下書きをすべて消去 (元に戻せない)」など。
- 部品セレクタ・画像エクスポート設定の入力欄: 「一覧の分け方」「部品名・キーワードで絞り込み」
  「基板の外側を透過 (OFF なら白)」など。
- 「？」バッジ (オブジェクト一覧・部品エディタ・基板エディタ): 操作の対応表 (「ダブルクリック:
  その位置へ移動」) や要点だけの形にした。
- 「操作のカスタマイズ」の各コマンドの説明 (ツリーのツールチップ): 「選択中の部品を90度回転」
  のような名詞句にした。
- 表示メニューの「操作のカスタマイズ...」「ツールバーのカスタマイズ...」に付いていた長い説明は
  削除した (メニューの項目にはツールチップが出ないので、そもそも表示されていなかった)。

## 基板メニュー (基板を選ぶ導線)

以前は基板を設計データに使うには「ライブラリ → ライブラリ管理...」を開き、ツリーで基板を選んで
「現在のデザインに使用」を押すしかなかった。

- **メニューバーに「基板(B)」** を追加した (「表示」と「ライブラリ」の間)。
  - ライブラリに入っている基板の一覧。名前の右に格子の大きさ (`72×47`) を出す。基板を持つ
    ライブラリが1つならそのまま並べ、複数ならライブラリごとのサブメニューに分ける。並びは
    ライブラリ管理のツリーと同じ名前順。今使っている基板にはチェックが付く。
  - 選ぶとその基板をそのまま設計データに使う (Undo で戻せる。ライブラリ管理の「現在のデザインに
    使用」と同じ動作)。
  - 「現在の基板を編集...」: 基板エディタで現在の基板を直す (Undo で戻せる)。基板エディタが扱わない
    取込専用の項目 (変形穴配置・ランドカット・取付穴) は引き継ぎ、幅マーカー (外形) はサイズが
    変わらないときだけ引き継ぐ。開いて OK を押しただけで PasS 取込基板の外形などが消えないように
    するため。
  - 「新規基板...」: 基板エディタで新しい基板を作り、設計データに使う (ライブラリには入れない)。
  - 「現在の基板をマイライブラリに登録」: 今の基板をマイライブラリに追加する。id が重なるときは
    `-2` などを付けて別の id にする。
- **ツールバーの先頭に基板ボタン** (ツールツールバーの先頭、コマンド ID `toolbar.tools.board`)。
  文字列が現在の基板 (`基板: ICB-504 (72×47)`、未設定なら `基板: 未設定`) を兼ね、押すと上と同じ
  メニューが開く。ツールチップは基板の詳細 (穴数・ピッチ・片面/両面・外形寸法 mm)。Undo/Redo で
  基板が戻ったときも追従する。「ツールバーのカスタマイズ」の一覧でのコマンド名は「基板」。
- **基板が未設定のあいだ、表面/裏面のビュー中央に案内**を出す (「基板が未設定 / 「基板」メニュー
  から選択」)。画像エクスポートには写らない (ビューに描くもので、シーンには含まれないため)。

## 配線の太さ

配線・被覆配線とも、入力中のプレビュー・確定後の線の両方を太くした。

| 層 | 以前 | 以後 |
| --- | --- | --- |
| 裸線 (表/裏) | 1.0 単位 (0.25mm) | 2.5 単位 (約0.64mm)、画面上で最低 2px |
| 被覆配線 (表/裏) | 1.0 単位、破線 | 4.0 単位 (約1.0mm)、画面上で最低 3px、破線 |
| 外形線 | 0.6 単位 | 0.6 単位、画面上で最低 1px |
| 入力中のプレビュー | 画面上 1.2px の破線 | 確定後と同じ太さ・線種を 75% の不透明度で。カーソルへ伸びる区間だけ破線 |

- 縮小表示でも細くなりすぎないよう、画面上の最小幅を保証する。ただし再描画の取り残しを防ぐため、
  アイテムの外接矩形の余白 (6単位) を超える太さにはしない。
- 被覆配線の破線は「線幅2つ分の線・1つ分の隙間」で、線端は平ら (丸い線端だと太い破線の隙間が
  埋まるため)。
- 選択時の黒縁・同一ネットの強調 (シアンの縁取り)・頂点ハンドルも、線の太さに合わせて大きくした。
- クリックの当たり判定は見た目より少しだけ広い幅 (裸線 3.5 単位、被覆配線 5 単位)。
- 画像エクスポートの線も同じ太さになる。

  ボタン・部品セレクタ・ビュー中央の案内) と、新規の `board-menu`。
